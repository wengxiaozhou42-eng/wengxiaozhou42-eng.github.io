这是我的第一篇文章。

我想有一个属于自己的地方，记录正在学的东西、做过的小项目，以及一些不想忘记的想法。社交平台上的内容会被时间线冲走，而放在自己仓库里的东西会一直留着，随时可以回来修改。

## 为什么选纯 HTML / CSS 加 Markdown

- 写文章只需要一个 Markdown 文件，不用打开笨重的编辑器
- 页面结构足够简单，按 F12 打开开发者工具就能看清每一处样式
- 不需要 Node.js、npm 和前端框架，也就没有依赖升级和打包配置的负担
- 内容存在 Git 仓库里，每次修改都有记录，改错可以退回去

## 我想在这里记录什么

- 学到的新概念，以及当时踩过的坑
- 做项目时遇到的问题和最后的解决办法
- 读过的文章和书里值得留下来的那几句话
- 下一步想尝试的事情

## 以后怎么继续写

在 `_posts` 文件夹里新增一个 `YYYY-MM-DD-title.md` 文件，改好开头的标题、日期和摘要，正文直接用 Markdown 写。推送到 GitHub 之后，GitHub Actions 会自动把 Markdown 编译成 HTML 并发布。

慢一点写，但要一直写下去。
